# Создание вертикальных шортсов для «КиноЖдун»

Этот навык описывает полный пошаговый процесс автономного создания брендированных шортсов о премьерах фильмов и сериалов, а также их публикации в каналы проекта.

## 1. Структура и параметры шортса

* **Разрешение:** 1080×1920 (вертикальный 9:16), 30 fps, H.264/AAC.
* **Длительность:** 24–28 секунд.
* **Голос:** `edge_tts` с голосом `ru-RU-DmitryNeural` и скоростью `+8%`.
* **Оверлей:** Фирменный стиль КиноЖдуна (тёмно-зелёный #121a11, неоновый акцент #d4fa58).
* ⚠️ **Важное правило:** Никаких надписей «трейлер за 25 секунд» в шапке. Только бейдж и интригующий хук.

## 2. Пошаговый пайплайн производства

### Шаг 1: Подготовка исходников
1. Выбрать фильм или сериал из ближайших премьер.
2. Скачать официальный трейлер в 720p через `yt-dlp`.
3. Составить 25-секундный цепляющий сценарий (завязка, конфликт, интрига, дата выхода, призыв сохранить в КиноЖдуне).

### Шаг 2: Генерация озвучки и таймингов
1. Сгенерировать WAV-аудиодорожку через `edge_tts.Communicate(text, "ru-RU-DmitryNeural", rate="+8%")`.
2. Извлечь точные тайминги фраз (Word/Sentence boundaries).

### Шаг 3: Сборка субтитров (ASS)
1. Сгенерировать файл `.ass` с разрешением `PlayResX: 1080`, `PlayResY: 1920`.
2. Позиционировать снизу: `MarginV: 460`.
3. Максимум 2 строки на фразу с явным `\N`.
4. Подсвечивать ключевое слово фразы неоновым лаймом: `{\c&H58FAD4&}`.
5. Анимация появления: `{\fscx95\fscy95\t(0,70,\fscx100\fscy100)}`.

### Шаг 4: Генерация графического оверлея
1. Создать 1080×1920 PNG с прозрачностью через Pillow:
   * Верхний бейдж: `🍿 КИНОЖДУН | ПРЕМЬЕРА` (Segoe UI Bold 30pt, фон (18, 26, 17, 230), рамка #d4fa58).
   * Хук: Segoe UI Bold 48pt на Y=185, белый с черным контуром.
   * Рамка центрального окна: Y=320..1224 (1080×904 px).
   * Нижний блок: название проекта (#d4fa58, 42pt), метаданные (платформа + дата, 28pt), кнопка CTA `👉 Сохрани в КиноЖдуне, чтобы не забыть` (30pt).

### Шаг 5: Монтаж и композитинг (FFmpeg)
1. Нарезать 10–13 динамичных кадров из трейлера с размытым фоном и центрированным видео.
2. Собрать кадры через `concat`.
3. Применить сайдчейн-даккинг: оригинальный звук трейлера приглушается под голос диктора.
4. Вшить субтитры через `-vf ass=captions.ass` (запуск с `cwd=out_dir`, чтобы избежать бага с двоеточием диска в Windows).
5. Экспортировать с флагом `-movflags +faststart`.
6. Сгенерировать постер `shorts_poster.jpg` и превью-сетку 3×3 `shorts_review_tile.jpg`.

### Шаг 6: Публикация
1. **Telegram-канал (`@kinojdun_channel`):**
   * Вызов `sendVideo` с `parse_mode="HTML"`, видео, постером и описанием.
2. **VK Сообщество (`242059739`):**
   * **Истории:** Получение URL через `stories.getVideoUploadServer`, загрузка через `curl.exe -F video_file=@...`, сохранение через `stories.save`.
   * **Стена:** Анонс через `wall.post` со ссылкой на сервис и просмотр истории.
