# КиноЖдун во ВКонтакте

Бот использует сообщения сообщества и Bots Long Poll API. Поддерживает поиск,
карточки с постерами, отслеживание фильмов и сериалов, личные даты, удаление,
проверку статуса, напоминания о премьерах и новых сериях. Кнопки списка
разбиты на страницы по восемь проектов.

В `.env` задайте `VK_BOT_TOKEN`, `VK_BOT_GROUP_ID` и `TMDB_API_KEY`.
`VK_BOT_URL` управляет ссылкой на сайте. Токен чата отделён от
`VK_ACCESS_TOKEN` и `VK_GROUP_ID`, используемых для публикаций на стене.

Запуск: `python -m vk_bot` или `docker compose up -d --build kinozhdun-vk-bot`.
При запуске бот включает сообщения, возможности бота и события
`message_new` / `message_event`. Токен должен иметь права `messages`,
`manage`, а для постеров — `photos`.

Данные VK хранятся в отдельной `data/kinozhdun_vk.db`. Поле `telegram_id`
общей ORM внутри этой базы содержит VK ID: базы разных платформ не смешиваются.
Курсор Long Poll и последние ID событий сохраняются в `data/vk_bot_poll.json`.
Проверка здоровья: `data/vk_bot_ready.json` и Docker healthcheck.

Ссылки с сайта передают `ref=c_movie_ID` / `ref=c_tv_ID` и
`ref_source=kinojdun`. После начала диалога бот открывает карточку проекта;
добавление в список требует нажатия кнопки подтверждения.

Проверки: `python -m unittest tests.test_vk_bot tests.test_bot_dropdown`.
Скрипт `scripts/deploy_vk_bot.py` сохраняет резервную копию и публикует
только исходники VK-бота, его общие зависимости и изменения выбора на сайте.
Секреты не входят в diff и manifest.
