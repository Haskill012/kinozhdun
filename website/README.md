# Локальный сайт КиноЖдун

Сайт использует существующий Python-стек; новые зависимости не нужны.
Запуск из корня проекта:

```powershell
.venv/Scripts/python.exe -m website
# либо
powershell -ExecutionPolicy Bypass -File ./start_site.ps1
```

Адрес: http://127.0.0.1:8099. Оставьте процесс работающим: фоновая
редакция запускается при старте и затем каждый час. При выключенном компьютере
или остановленном процессе новые материалы не создаются.

## Что реализовано

- Адаптивная главная, новости, фильмы, сериалы, календарь, статьи, поиск и пагинация.
- Прямые ссылки в существующий бот `c_movie_ID` / `c_tv_ID` и канал.
- Автономная редакция сравнивает снимки TMDB: новые даты, изменения дат,
  изменение статуса, наступление даты выхода, новые официальные трейлеры.
- При первом запуске создаются статьи о ближайших датах. Статьи про трейлеры
  и статусы появляются при изменениях между проверками, а не из старого каталога.
- Опубликованные подтверждённые сообщения канала импортируются без записи
  в базу бота; подозрительные даты в недельных дайджестах отфильтровываются.
- Уникальный отпечаток события предотвращает повторные публикации после рестартов.
- Материалы и снимки сохраняются в `data/website.db`; база бота не изменяется.
- Нет отправки сообщений или изменения режима публикации в Telegram.
- HTML формируется на сервере; canonical, Open Graph, Article/NewsArticle,
  `sitemap.xml`, `robots.txt`, `feed.xml`, человекочитаемая страница 404.

## Автоматизация и источники

Используется `TMDB_API_KEY` из существующего `.env`. При сбое сети сайт сохраняет
контент и автоматически пробует снова на следующем цикле. `/health` показывает
последний успешный цикл, ошибки и количество материалов. Секреты в ответ не попадают.
Каталог новых фильмов и сериалов ограничен популярными результатами TMDB;
Фильмы дополнительно выбираются по международной дате премьеры в следующие 120 дней.
это не полный мониторинг всех новостей киноиндустрии. Интервью, слухи, пресс-релизы
и рецензии пока не собираются. Для такого расширения нужны дополнительные разрешённые
источники. AI-ключ не нужен: текст формируется из проверяемых данных по шаблонам.

TMDB — каталог сообщества, а не официальный пресс-центр. Даты могут различаться по
регионам. Для сериалов используется следующий эпизод, а не дата первого сезона.
Пользователю показываются источник и эти ограничения. Права и условия использования:
https://developer.themoviedb.org/docs/faq

## Конфигурация

Все `SITE_*` параметры необязательны. Значения по умолчанию приведены в `.env.example`.
`SITE_CHANNEL_URL` нужен, если `TELEGRAM_CHANNEL_ID` содержит числовой ID вместо username.
`SITE_DATABASE_PATH` позволяет переопределить путь собственной базы сайта.
`SITE_SYNC_INTERVAL_MINUTES=60`, `SITE_BATCH_SIZE=12` задают период и объём выборки.
Можно применять `HTTPS_PROXY` через окружение для подключения к TMDB.

Локально индексация отключена. Для публичного размещения нужны:

1. Постоянно работающий сервер, HTTPS и домен.
2. `SITE_BASE_URL=https://ваш-домен` и `SITE_PUBLIC=true`.
3. Запуск сайта как сервиса с автоматическим перезапуском; готов вариант Docker Compose.
4. Добавление `/sitemap.xml` в Google Search Console и Яндекс Вебмастер после размещения.

Сайт пока не опубликован. SEO-разметка помогает поисковикам понимать страницы,
но не гарантирует позиции или индексацию:
https://developers.google.com/search/docs/appearance/structured-data/article
