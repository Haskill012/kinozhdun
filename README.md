# 🎬 КиноЖдун — Telegram-бот для отслеживания выхода сериалов и фильмов

Умный Telegram-бот, который следит за выходом новых сезонов сериалов и продолжений фильмов. Вы просто присылаете боту название того, что ждёте — а он автоматически мониторит официальные базы и присылает уведомление с датой выхода и ссылкой на источник в тот же момент, когда она появляется в сети.

---

## ✨ Возможности

- 🔍 **Удобный поиск**: отправьте любое название сериала или фильма (на русском или английском) — бот выдаст подходящие результаты с постерами, годами выпуска и рейтингами.
- 📺 **Авто-отслеживание новых сезонов**: бот отслеживает анонсы `next_episode_to_air` и новые сезоны в каталоге **TMDB**.
- 🎬 **Отслеживание фильмов и сиквелов**: мониторинг даты выхода анонсированных картин.
- 🔗 **Ссылка на источник**: каждое уведомление содержит прямую ссылку на проверенный первоисточник (TMDB).
- 📅 **Ручная дата премьеры**: если вы знаете примерную дату или хотите напоминание в конкретный день — установите её вручную через команду `/setdate`.
- ⏰ **Напоминания перед премьерой**: за 3 дня до даты выхода бот пришлёт напоминание, чтобы вы подготовили попкорн 🍿.
- ⚡ **Кэширование и дедупликация**: даже если 1000 пользователей отслеживают один сериал, бот опрашивает TMDB API всего один раз за цикл проверки.

---

## 🛠 Стек технологий

- **Python 3.11+**
- **aiogram 3.x** — современный асинхронный фреймворк для Telegram Bot API
- **SQLAlchemy 2.0 (async)** + **aiosqlite** — легковесная асинхронная база данных SQLite (не требует отдельного сервера)
- **TMDB API v3 / v4** — официальный каталог фильмов и сериалов The Movie Database
- **APScheduler** — планировщик периодических фоновых проверок
- **Docker & Docker Compose** — быстрая контейнеризация и развёртывание

## 🚀 Быстрый старт

### 1. Получение ключей

1. **Telegram Bot Token**:
   - Откройте бота [@BotFather](https://t.me/BotFather) в Telegram.
   - Отправьте команду `/newbot` и следуйте инструкциям.
   - Скопируйте полученный токен.

2. **TMDB API Key**:
   - Зарегистрируйтесь на [The Movie Database (TMDB)](https://www.themoviedb.org/).
   - Перейдите в [Настройки -> API](https://www.themoviedb.org/settings/api).
   - Создайте ключ API (Developer) и скопируйте `API Key (v3 auth)` или `API Read Access Token (v4 auth)`. Бот поддерживает оба формата!

---

### 2. Запуск локально (Python)

```bash
# Клонируйте репозиторий или перейдите в папку проекта
cd "d:\ВАЙБКОДИНГ\ПРОЕКТЫ\КиноЖдун"

# Создайте виртуальное окружение
python -m venv venv

# Активируйте виртуальное окружение
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# Linux / macOS:
# source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt

# Создайте файл конфигурации .env на основе примера
cp .env.example .env
```

Заполните файл `.env`:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
TMDB_API_KEY=ваш_ключ_от_TMDB
DATABASE_URL=sqlite+aiosqlite:///./data/kinozhdun.db
CHECK_INTERVAL_HOURS=6
ANNOUNCED_CHECK_INTERVAL_HOURS=2
MAX_ITEMS_PER_USER=50
```

Запустите бота:

```bash
python -m bot
```

---

### 3. Запуск через Docker Compose (Рекомендуется для серверов)

```bash
# Создайте и настройте .env файл
cp .env.example .env
nano .env

# Соберите и запустите контейнер в фоновом режиме
docker compose up -d --build

# Просмотр логов
docker compose logs -f
```

## 📱 Команды бота

| Команда | Описание |
|---|---|
| `/start` | Запуск бота, регистрация и краткий гид |
| `/help` | Полная справка по всем возможностям |
| `текст сообщения` | Поиск сериала или фильма по названию |
| `/list` | Показать ваш текущий список отслеживания |
| `/status` | Принудительно запросить свежие данные по вашему списку |
| `/setdate` | Указать свою дату премьеры для напоминания |
| `/remove` | Удалить сериал или фильм из списка отслеживания |
