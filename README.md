# 🎬 КиноЖдун (@kinojdun_bot) — Личный трекер премьер

Умный Telegram-бот, который следит за выходом новых сезонов сериалов и продолжений фильмов. Вы просто присылаете боту название того, что ждёте — а он автоматически мониторит официальные базы и присылает уведомление с датой выхода и ссылкой на источник в тот же момент, когда она появляется в сети.

---

## 🌐 Локальный сайт

Сайт с автономной редакцией: `.venv/Scripts/python.exe -m website`.
Откройте http://127.0.0.1:8099. Инструкция и настройки: [website/README.md](website/README.md).

Для серверного размещения подготовлены Docker Compose (бот, сайт, Caddy), HTTPS для
`kinojdun.ru` и `www.kinojdun.ru`, а также обновление из ветки `master` через cron.
Фактический статус сервера проверяется отдельно. Подробности развёртывания — в
[website/README.md](website/README.md).

## ✨ Возможности и механики органического роста

### Основной функционал
- 🔍 **Поиск и предпросмотр**: отправьте название фильма или сериала на русском или английском — бот покажет карточку с платформой (HBO, Netflix, Apple TV+ и др.), рейтингом, сезонами и сюжетом.
- ➕ **Явное добавление в отслеживание**: кнопка «➕ Добавить в отслеживание» на карточке любого найденного тайтла.
- 📺 **Авто-отслеживание новых сезонов**: бот отслеживает анонсы `next_episode_to_air` и новые сезоны в каталоге **TMDB**.
- 🎬 **Отслеживание фильмов и сиквелов**: мониторинг даты выхода анонсированных картин.
- 🌐 **Карточки на сайте**: названия фильмов и сериалов в поиске, списках, уведомлениях и шеринге ведут на карточку КиноЖдуна с полной историей новостей проекта.
- 🔗 **Ссылка на источник**: каждое уведомление содержит прямую ссылку на проверенный первоисточник (TMDB).
- 📅 **Ручная дата премьеры**: возможность указать дату вручную через меню или команду `/setdate` (в формате `ДД.ММ.ГГГГ`).
- ⏰ **Напоминания перед премьерой**: за 3 дня до даты выхода бот пришлёт напоминание 🍿.

### Механики вирального роста
1. **Виральное распространение отдельных фильмов и сериалов**:
   - После добавления любого фильма или сериала появляется кнопка **«📤 Поделиться с другом»**.
   - Нативная ссылка `t.me/share/url` позволяет в 1 тап отправить красивое сообщение с персональным deep link (`/start c_<media_type>_<tmdb_id>`) в любой личный чат или группу Telegram.
   - Получатель открывает специальный экран **«🍿 Тоже ждёшь «...»?»** и может добавить проект в свой трекер одним нажатием **«🔔 Отслеживать»** без повторного поиска.
   - Фиксируется источник привлечения (`referral_source` и `referrer_id`).

2. **Раздел «Мой Кинождун» (шеринг списка ожидания)**:
   - В разделе списка ожидания доступна кнопка **«📤 Поделиться списком ожидания»**.
   - Генерируется изолированный **снапшот** списка на момент отправки с уникальным безопасным токеном (`/start w_<token>`).
   - Приватные данные владельца списка (ID, юзернейм) полностью скрыты от получателей.
   - Получатель видит карточку со списком фильмов/сериалов друга, может отслеживать отдельные тайтлы кнопками **«➕»** либо нажать **«➕ Отслеживать всё»** (с экраном подтверждения перед добавлением).

3. **Автоматический Telegram-канал «Кинождун»**:
   - Автоматическая публикация общих подборок и дайджестов премьер. Личные обновления по отслеживаемым тайтлам отправляются только их подписчикам в бот и не создают посты в канале.
   - Защита от дублей по стабильному хэшу (`content_hash`).
   - Антиспам-фильтр минимального интервала между публикациями (`CHANNEL_MIN_POST_INTERVAL_MINUTES`).
   - Очередь публикаций (`pending / published`).
   - Кнопка **«🔔 Отслеживать в боте»** с deep link (`/start ch_<post_id>`), ведущая прямо в бота с быстрым добавлением тайтла.

4. **Аналитика воронки роста (9 ключевых событий)**:
   - `content_shared`, `share_link_opened`, `content_followed_from_share`
   - `watchlist_shared`, `watchlist_link_opened`, `watchlist_item_followed`, `watchlist_follow_all`
   - `channel_link_opened`, `content_followed_from_channel`

## 🛠 Стек технологий

- **Python 3.11+**
- **aiogram 3.x** — современный асинхронный фреймворк для Telegram Bot API
- **SQLAlchemy 2.0 (async)** + **aiosqlite** — легковесная асинхронная база данных SQLite
- **TMDB API v3 / v4** — официальный каталог фильмов и сериалов The Movie Database
- **APScheduler** — планировщик периодических фоновых проверок и публикаций
- **aiohttp** — сайт с серверным HTML и автономной редакцией; отдельная SQLite-база `data/website.db`
- **Docker Compose + Caddy** — серверный запуск и HTTPS

## 🚀 Быстрый старт

### 1. Настройка окружения
```bash
# Скопируйте шаблон окружения
cp .env.example .env
```

Заполните `.env`:
```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
TMDB_API_KEY=ваш_tmdb_api_key
DATABASE_URL=sqlite+aiosqlite:///./data/kinozhdun.db
BOT_USERNAME=kinojdun_bot

# Канал (опционально)
TELEGRAM_CHANNEL_ID=@kinojdun_channel
CHANNEL_POSTING_ENABLED=true
# SAFE MODE (false) или AUTO MODE (true)
CHANNEL_AUTO_PUBLISH=false
CHANNEL_MIN_POST_INTERVAL_MINUTES=15
ADMIN_USER_IDS=12345678,98765432
```

### 2. Запуск тестов
```bash
python -m unittest discover tests
```

### 3. Запуск бота
```bash
python -m bot
```

## 📢 Публичный Telegram-канал «Кинождун 🍿»

Канал работает полностью автоматически и привлекает пользователей в `@kinojdun_bot`:
1. **Разделение публикаций**:
   - 🔔 **Бот**: личные уведомления о датах, релизах, изменениях статуса и напоминания за 3 дня — только по отслеживаемым фильмам и сериалам.
   - 🍿 **Канал**: «Что выходит сегодня» (`daily_digest` — в 09:30 по Москве) и «Главные премьеры недели» (`weekly_digest` — по понедельникам в 10:00 по Москве).
   - Обновления личного трекера не создают публикации для канала. Старые одиночные новости в очереди доступны для ручной модерации, но не публикуются автоматически и не задерживают подборки.
2. **Защита от дублей (Event Fingerprint)**:
   - Исключает дублирование новостей от разных источников и повторные публикации.
   - Разделяет события: анонс даты и перенос даты — это разные события, не блокирующие друг друга.
3. **Фильтрация достоверности**:
   - Автоматическая публикация только подтверждённых данных (`confirmed`). Слухи и SEO-мусор отсекаются.
4. **Режимы работы**:
   - **SAFE MODE** (`CHANNEL_AUTO_PUBLISH=false`): бот готовит подборки, формирует посты и складывает их в очередь модерации. Администратор подтверждает кнопкой в боте.
   - **AUTO MODE** (`CHANNEL_AUTO_PUBLISH=true`): подборки и дайджесты публикуются в канал автоматически с соблюдением интервала антиспама (`CHANNEL_MIN_POST_INTERVAL_MINUTES`).
5. **Администрирование в боте** (для пользователей из `ADMIN_USER_IDS`):
   - `/admin` или `/queue` — просмотр очереди публикаций с кнопками `[✅ Опубликовать]`, `[✏️ Изменить текст]`, `[❌ Отклонить]`.
   - `/channel_test` — проверка прав публикации бота в канале.
   - `/stats` — аналитика воронки канала (посты, переходы, конверсия).
   - `/mode` — текущий режим работы.
6. **Контекстные CTA и Deep Links**:
   - Кнопка под постом в канале ведёт по персональной ссылке `https://t.me/kinojdun_bot?start=ch_<post_id>`.
   - Экран в боте: **«🍿 Тоже ждёшь «Название»?»** с кнопкой **«🔔 Отслеживать»** в 1 клик.

## 🧪 Ручная проверка сценариев

1. **Сценарий 1 (Виральный шеринг тайтла)**:
   - Напишите в боте название фильма (например, `Фоллаут`).
   - Нажмите `➕ Добавить в отслеживание`.
   - В появившемся сообщении нажмите `📤 Поделиться с другом`.
   - Telegram откроет выбор чата со ссылкой вида `https://t.me/kinojdun_bot?start=c_tv_82856`.
   - Перейдите по ссылке с другого аккаунта — откроется карточка `🍿 Тоже ждёшь...?` с кнопкой `🔔 Отслеживать`.

2. **Сценарий 2 («Мой Кинождун» — расшаривание списка)**:
   - В главном меню нажмите `🍿 Мой список ожидания`.
   - Под списком нажмите `📤 Поделиться списком ожидания`.
   - Бот сгенерирует снапшот и покажет кнопку `📤 Отправить друзьям в Telegram` со ссылкой `https://t.me/kinojdun_bot?start=w_<token>`.
   - При переходе по ссылке получатель видит список ожидания, кнопки добавления по отдельности и кнопку `➕ Отслеживать всё`.

3. **Сценарий 3 (Канал с новостями и SAFE MODE / AUTO MODE)**:
   - В SAFE MODE при создании подборки администратор получает уведомление с кнопкой `[✅ Опубликовать]`.
   - После публикации подборки в канале нажмите под постом кнопку `🔔 Отслеживать ...`.
   - Откроется бот со ссылкой `start=ch_<post_id>`, покажет подборку и предложит найти и добавить интересующие тайтлы в отслеживание.
